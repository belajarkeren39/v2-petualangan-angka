PETUALANGAN ANGKA — EDISI ANIME 2D

CARA MEMBUKA
1. Ekstrak seluruh ZIP terlebih dahulu.
2. Buka index.html menggunakan Chrome atau Edge.
3. Pilih mode, kelas, dan durasi, lalu Mulai Petualangan.
4. Jika tanpa kamera, pilih Lewati Latihan & Mulai.
5. Klik/sentuh jawaban atau gunakan Q/W/A/S (P1), I/O/K/L (P2).

Buka pratinjau-animasi.html untuk melihat karakter berukuran besar
dan mencoba animasi menyapa, jawaban benar, dan jawaban salah.

ISI FOLDER
index.html                    : game utama
pratinjau-animasi.html         : demo animasi karakter
aset/karakter/                : PNG transparan Raka dan Robo Arka
aset/background/              : ilustrasi Kerajaan Angka
aset/css/                     : gaya game dan animasi
aset/js/                      : logika game dan reaksi karakter
aset/vendor/                  : pustaka tampilan Tailwind lokal
PROMPT-ILUSTRASI.txt           : prompt ilustrasi dan metode pembuatan

ANIMASI
Animasi memakai transformasi CSS pada ilustrasi 2D PNG: gerak idle,
melayang, menyapa, melompat ketika benar, dan bergoyang ketika salah.
Bukan video atau animasi rangka/frame-by-frame. Animasi mengikuti
pengaturan Kurangi Gerakan pada perangkat dan berhenti saat game dijeda.

AKSES INTERNET & KAMERA
Ilustrasi, animasi, tampilan, serta mode klik/keyboard tersedia lokal.
Sensor tangan memerlukan internet untuk mengambil MediaPipe dan modelnya,
serta izin kamera. Jika browser menolak kamera saat membuka file lokal,
gunakan hosting HTTPS atau localhost; mode klik/keyboard tetap bisa dipakai.
Gambar kamera ditampilkan transparan di atas latar. Karakter tengah
disembunyikan saat kamera aktif agar zona wajah tetap jelas.

Sumber: file HTML yang diberikan pengguna; mekanik soal dan skor dipertahankan.
Ilustrasi dibuat menggunakan imagegen bawaan. Aset menggunakan jalur relatif;
jangan memindahkan index.html sendirian tanpa folder aset.

PEMERIKSAAN
Diuji di Chrome: pemuatan aset lokal, mode offline klik/keyboard,
jawaban benar/salah dan reaksi karakter, jeda/lanjut, hasil, duel 2P,
pengaturan kurangi gerakan, serta tampilan desktop dan lanskap 844x390.
Sensor kamera fisik belum diuji. Untuk ponsel gunakan orientasi lanskap.
